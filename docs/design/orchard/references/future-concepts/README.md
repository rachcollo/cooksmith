# Future concepts — NOT migration targets

These files are the **aspirational** Orchard designs. They intentionally show
functionality Cooksmith does **not** have today and are **excluded** from the visual
migration (see `../../06-route-build-notes.md` and `../../00-current-state.md`).

- `Cooksmith Home + Plan (future).dc.html` — a tonight's-dinner **Home dashboard** and a
  **fortnight** (2-week) planner with persistent locks.
- `Cooksmith Desktop (future).dc.html` — the desktop versions of the same aspirational
  dashboard / fortnight.

They are kept because they are valuable direction for later product stories. **Do not
implement from these.** Each capability they depict needs its own approved product story:
Home dashboard, fortnight planner + week toggle + persistent locks, recipe filter chips
& fixed categories, shopping retailer copy-export, pantry segmented stock levels.

The migration-safe references (current functionality) are one level up in `references/`.
