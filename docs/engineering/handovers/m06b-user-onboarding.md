# Milestone 6B handover

Milestone 6B adds durable first-run onboarding after Milestone 6A authentication. The hosted Supabase migration must be applied through the approved production migration process before the merged application is used for onboarding.

Future work may build on the completed profile, active owner membership, household settings, and household-level dietary/allergy defaults. Do not duplicate the bootstrap flow or infer onboarding completion from client storage. Milestone 6C has not begun.
