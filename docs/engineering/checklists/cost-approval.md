# Cost approval checklist

Complete this checklist and obtain explicit approval before a change introduces a paid provider, adds a hosted service, changes an existing provider tier or increases baseline cost by more than A$20 per month.

- [ ] Problem being solved is stated in user or operational terms.
- [ ] Measured limitation of the current approach is documented with evidence.
- [ ] Expected monthly cost in Australian dollars is calculated for friend-test and next-stage usage.
- [ ] Expected annual cost in Australian dollars is calculated.
- [ ] Usage assumptions, taxes, currency conversion and variable-cost risks are stated.
- [ ] Free, included-tier, self-hosted and simpler alternatives have been considered.
- [ ] The cheapest suitable alternative and the reason it was not selected are recorded.
- [ ] Data handling, security, reliability and vendor lock-in have been reviewed.
- [ ] Cancellation, data export and technical rollback path are documented.
- [ ] Named owner has explicitly approved the provider and cost before activation.

Record the approval in the pull request and relevant ADR. No response or assumed future revenue is not approval.
