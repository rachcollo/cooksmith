# Cooksmith agent instructions

- Use Australian/UK English and never use em dashes in product copy.
- Voice: warm, wry, plain-speaking, anti-hype and permission-giving. Humour must clarify or relieve, never shame.
- Preserve mobile-first usability and accessible labels.
- Keep the MVP deliberately small. Avoid abstractions without a current use.
- Run `npm run build` after changes and fix all failures.
- Never commit credentials or service keys.
